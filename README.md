# S7 Opti – pobieranie

**[⬇ Pobierz S7Opti.exe](https://raw.githubusercontent.com/Sevenek0/s7-opti-releases/main/S7Opti.exe)**

S7 Opti to program do optymalizacji komputera z systemem Windows 10/11. Pozwala na:
- czyszczenie niepotrzebnych plików;
- zmianę ustawień wydajności i prywatności;
- usuwanie zbędnych aplikacji;
- sprawdzenie temperatur i sterowników.

Każdą zmianę można cofnąć.

Do uruchomienia potrzebny jest klucz licencyjny.

To repozytorium zawiera tylko pliki do pobrania:
- `S7Opti.exe` – najnowsza wersja programu;
- `latest.json` – informacja o wersji dla automatycznych aktualizacji, podpisana cyfrowo przez wydawcę.

Zainstalowany program sam sprawdza tutaj, czy jest nowsza wersja. Aktualizacja jest instalowana tylko wtedy,
gdy jej podpis cyfrowy się zgadza.
